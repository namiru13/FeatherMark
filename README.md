# FeatherMark

Windows向けの羽のように軽量・高速なローカルMarkdownビューアデスクトップアプリケーションです。Tauri (Rust) と React (Vite / TypeScript) で構築されています。

## 主な機能

### 1. Markdownレンダリング & 表現力
- **高速Rustパース & セキュリティ**:
  - Rust製パーサー（`pulldown-cmark`）による超高速レンダリングと画像バイナリストリーミング。
  - `DOMPurify` による徹底したサニタイズ処理を実施し、悪意あるスクリプトや不正HTMLを無害化して安全に表示。
  - GitHubスタイル（`github-markdown-css`）に準拠した読みやすいデザイン。
- **コードブロックの軽量シンタックスハイライト**:
  - フロントエンドに巨大なJSライブラリ（MonacoやHighlight.js等）を持ち込まず、Rust側（`syntect` クレートの純Rustパース）でMarkdown解析時にCSSクラスを付与する低リソース設計。
  - ダーク・ライト両テーマに最適化されたGitHubスタイル配色、言語名バッジ表示、ワンクリックコピーボタン（完了チェック表示付き）を搭載。
- **表（テーブル）表示対応**:
  - GitHub Flavored Markdown (GFM) 形式のテーブル記法（ヘッダー、区切り線、アライメント指定など）をHTMLテーブルとして美しく描画。
- **画像（Image）表示対応**:
  - Web上の画像（`https://...`, `http://...`）の自動読み込み・表示。
  - ローカル画像（相対パス `./images/fig.png`、絶対パス `C:\...`）をTauriバックエンド経由で安全に読み込み表示（日本語パス・URLエンコード対応）。
  - 読み込みエラーやパス未検出時の分かりやすい代替フォールバックカード表示。
- **スマートリンクナビゲーション**:
  - **外部Webリンク (`https://...`, `mailto:...`)**: OS既定のWebブラウザで開く。
  - **別Markdownファイルへのリンク (`./sub.md`, `../doc.md`)**: アプリ内で自動的に読み込んで切り替え表示（見出し指定 `#section` も対応）。
  - **同一ドキュメント内の見出しアンカー (`#見出し`)**: 該当見出し位置へスムーズスクロール。
  - **外部ファイルへのリンク (`.pdf`, `.png` 等)**: OS既定のアプリケーションで起動。
- **Mermaidダイアグラムの描画 & 対話的操作**:
  - フローチャート、シーケンス図、クラス図、ER図、ガントチャート、Gitグラフ、マインドマップ等のMermaid記法を自動レンダリング。
  - レンダリング分離（iframeプールワーカー）によるメインUIの高速・非同期描画とクラッシュ防止。
  - ダイアグラムのパン（ドラッグ移動）＆ズーム（ホイール拡大縮小）、リセット操作、SVG画像コピー/保存に対応。
  - 「ダイアグラム表示」と「生コード表示」のシームレスなトグル切り替え。
- **表示テーマ設定（ライト / ダーク / システム連動）**:
  - ツールバーの設定（⚙️）ボタンから「ライトモード」「ダークモード」「システム設定に連動」を自由に切り替え可能（Mermaidダイアグラムの配色も自動同期）。

### 2. ファイル操作 & ワークスペース管理
- **ファイルのクイックオープン (`Ctrl + P`)**:
  - `Ctrl + P` でVS Codeライクな検索モーダルをポップアップ表示。
  - ワークスペース（開いているフォルダ）内の全Markdownファイルをインクリメンタル（あいまい）検索し、`Enter` で即座にアクティブペインで開く（既存タブがあれば自動切り替え）。
  - 全文インデックスを作らずディレクトリメタデータのみを走査する超軽量・極小フットプリント設計。
- **VS Code風サイドバーエクスプローラー**:
  - 「フォルダを開く」ボタンから選択したフォルダのファイルツリーを表示。
  - ツリーの開閉展開、サイドバー幅のリサイズ、表示トグル (`Ctrl + B`)、一括折りたたみ、更新ボタンを搭載。
- **開いているファイルの自動リロード（ホットリフレッシュ）**:
  - VS Codeやメモ帳等の外部エディタでファイルが保存された際、自動的に再読み込みして最新状態を表示。
  - フォルダ全体の常時監視ではなく、各ペインで表示中のアクティブファイルのみをRustバックエンド（`notify`）でピンポイント監視する低リソース設計。
  - アトミック保存対応およびリロード前のスクロール位置保持を実現。
- **柔軟なファイルオープン**:
  - **ドラッグ＆ドロップ (D&D)**: エクスプローラー等から `.md` ファイルをウィンドウや指定ペインに直接ドラッグ＆ドロップ（オーバーレイガイド付き）。
  - **ファイル選択ダイアログ (`Ctrl + O`)**: 「ファイルを開く」ボタンから単一ファイルを直接読み込み。

### 3. マルチペイン & タブ管理
- **マルチペイン分割表示**:
  - 画面を最大3ペインまで分割し、複数のMarkdownドキュメントを並行して閲覧・比較。
  - ペイン間のタブドラッグ＆ドロップ移動、空ペインの自動終了に対応。
- **タブ管理 & 閉じたタブの復元**:
  - 複数Markdownファイルのタブ切り替え・ドラッグ並び替え。
  - `Ctrl + Shift + T` による最後に閉じたタブの復元。
- **タイトルバー連動**:
  - 開いたファイル名に合わせて、ウィンドウタイトルおよびドキュメントタイトルが「`ファイル名 - フォルダ名 - FeatherMark`」に自動更新。

### 4. 閲覧支援・差分比較・出力ツール
- **ページ内テキスト検索 (`Ctrl + F`)**:
  - フローティング検索バーによるキーワードハイライト表示。
  - 「前へ」「次へ」ボタンおよび `Enter` / `Shift + Enter` でのスムーズスクロール移動。
  - 総件数と現在インデックス（例: `2 / 15`）の表示、`Esc` によるハイライト解除・バー終了に対応。
- **Markdownファイルの差分比較（Diff機能 & Git Diff）**:
  - ツールバーのDiffアイコン、またはサイドバー/エディタタブの右クリックメニュー（「Git HEAD と差分比較」「Git コミット履歴と比較...」「別ファイルと差分比較...」）から起動。
  - **Git HEAD / 過去コミットとの差分比較**: 端末のGit CLIと連携し、最新コミット（HEAD）や過去のコミット履歴（`git log` 一覧モーダルから選択）と現在のローカル作業内容（ワーキングツリー）をアプリサイズ・常駐メモリ0MB増で高速差分比較。再計算ボタンによる編集後のホットリフレッシュ、Windowsコンソール非表示（`CREATE_NO_WINDOW`）に完全対応。
  - 同一ワークスペース内のファイル一覧（インクリメンタル検索対応）またはダイアログから比較先ファイルを選択可能。
  - Rustの `similar` クレートによる高速かつ高精度な差分検出（行単位・単語単位のインライン変更強調、テーブル・コードブロック枠全体の差分ハイライト対応）。
  - **Mermaid図の差分視覚化**: Mermaidダイアグラム内のノード・エッジの追加（緑）、削除（赤）、変更をダイアグラムおよびコード上で直感的にハイライト。
  - 3つの表示モード:「ビジュアル差分（統合表示）」「左右分割（テキスト差分）」「左右分割（ビジュアル差分）」。
  - 左右分割モードにおける滑らかな同期スクロール、タブとしての独立管理に対応。
  - **Overview Ruler & 差分ナビゲーション**:
    - スクロールバー横に差分の全体分布を可視化する「Overview Ruler」を配置。追加（緑）、削除（赤）、変更（黄色）のカラーピンと現在の閲覧範囲（ビューポート枠）を表示し、クリックやドラッグで瞬時に移動可能。
    - ツールバーの「▲ / ▼」ボタンやキーボードショートカット（`F7` / `Shift + F7` / `Alt + ↑↓`）で差分ブロック間を順次ジャンプ確認可能。ジャンプ先要素がふんわり光るフラッシュ演出付き。
- **印刷 / PDFエクスポート (`Ctrl + Shift + P`)**:
  - ツールバーの印刷ボタンまたは `Ctrl + Shift + P` から印刷・PDF出力ダイアログを起動。
  - ツールバーやサイドバー等のUIを自動的に非表示にし、Markdown本文を用紙（A4等）に最適化して出力。

### 5. 外部連携 & コンテキストメニュー
- **洗練された右クリックメニュー**:
  - サイドバー（ファイル・フォルダ）、タブバー、Markdownプレビュー領域のどこからでも右クリックで便利なコンテキストメニューを表示。
  - 半透明ぼかしのグラスモフィズムUI、画面端での見切れ自動反転防止を搭載。
- **「他のアプリで開く」メニュー**:
  - VS Code（`Code.exe` / `code` コマンドでフラッシュなし高速起動）
  - Windows標準「メモ帳」（`notepad.exe`）
  - OS既定の関連付けアプリ
  - 設定で指定したカスタムエディタ（Cursor、Obsidian、Sublime Text 等）
- **エクスプローラー連携 & パスコピー**:
  - **「エクスプローラーで表示」**: 対象ファイルがハイライトされた状態でWindowsエクスプローラーを開く。
  - **パスのコピー**: 「パスをコピー」「相対パスをコピー」で素早くクリップボードへ取得。
- **タブ操作メニュー**:
  - 「タブを閉じる」「他のタブを閉じる」「右側のタブを閉じる」をサポート。

### 6. キーボードショートカット

| カテゴリ | ショートカット | 機能 |
| :--- | :--- | :--- |
| **検索・移動** | `Ctrl + P` | ファイルのクイックオープン（あいまい検索モーダル） |
| | `Ctrl + F` | ページ内テキスト検索バーの表示（`Esc` で解除） |
| | `F7` / `Alt + ↓` | 差分表示時: 次の差分箇所へジャンプ |
| | `Shift + F7` / `Alt + ↑` | 差分表示時: 前の差分箇所へジャンプ |
| **ファイル・出力** | `Ctrl + O` | ファイルを開くダイアログ |
| | `Ctrl + Shift + P` | 印刷 / PDF保存 |
| **タブ操作** | `Ctrl + W` | アクティブタブを閉じる |
| | `Ctrl + Shift + T` | 最後に閉じたタブを復元 |
| | `Ctrl + Tab` / `Ctrl + PageDown` | 次のタブへ切り替え |
| | `Ctrl + Shift + Tab` / `Ctrl + PageUp` | 前のタブへ切り替え |
| | `Ctrl + 1` 〜 `9` | 指定番号のタブへジャンプ（`Ctrl + 9` で末尾タブ） |
| **表示・設定** | `Ctrl + B` | サイドバーの開閉切り替え |
| | `Ctrl + ,` | 設定画面の表示 |
| | `F11` | 全画面表示の切り替え（`Esc` で解除） |

## 開発環境の実行

```bash
# 依存関係のインストール
npm install

# フロントエンド単体での開発
npm run dev

# Tauriデスクトップアプリとしての起動
npm run tauri dev
```

## ビルド

```bash
# フロントエンドのビルド
npm run build

# デスクトップアプリのパッケージング
npm run tauri build
```
